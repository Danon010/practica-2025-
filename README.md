# Vulnerability Scanner 
 
Система автоматического сканирования уязвимостей в сетевой инфраструктуре и веб-приложениях. 
 
## ?? Возможности 
 
- Сетевое сканирование (Nmap) 
- Сканирование веб-приложений (OWASP ZAP) 
- Полное сканирование (OpenVAS) 
- RESTful API 
- Аутентификация и авторизация 
 
## ?? Быстрый старт 
 
```bash 
git clone https://github.com/yourusername/vulnerability-scanner.git 
cd vulnerability-scanner 
docker-compose up -d 
```
